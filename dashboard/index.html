Rebuilding the book from a message queue

The consumer rebuilds the book from BlazingMQ and compares it with a golden book built from the same feed. In the last run the broker rejected posts because the consumer lagged behind its queue limit. The feed handler filled the gaps through a retransmit callback that reads an in-process copy of the feed, so it simulates a retransmission service; BlazingMQ retransmitted nothing.
